# UX profile (draft from setup-ui-ux-skills)

Written without the interactive interview, so treat every line as a proposal and edit freely.

- **Aesthetic reference:** Custom. A physical handheld recorder: matte plastic shell, black scanline LCD, tactile caps and LEDs.
  Closest standard archetype for density and restraint: Apple Native. Hardware realism wins where they differ.
- **Accessibility target:** WCAG 2.1 AA. Text >= 4.5:1 on the LCD, UI glyphs >= 3:1, 44px minimum hit areas (extended with
  pseudo-elements where the visual is smaller), visible 3px focus rings, `prefers-reduced-motion` honoured.
- **Brand tone:** Utilitarian & Minimal. Sentence case, plain verbs, state names as nouns (Ready, Singing, Scored).
  The one all-caps label is the status line, taken from the reference hardware.
- **Icon library:** Project SVG, inline only (Lucide-derived stroke paths). No packages, no build step. One set, no emoji as icons.
- **Type:** Inter via the `Device Sans` family; swap point is `web/ui/fonts.css`.
- **Motion:** everything eases out (`cubic-bezier(.22,1,.36,1)`); one unprompted moment (power-on), plus the record light.

## Banned anti-aesthetics
- Gratuitous glassmorphism / `backdrop-filter`
- Floating pastel pill badges for ordinary metadata
- Decorative gradients as ornament (gradients are allowed only to model light on a physical surface)
- Neon glowing borders, rainbow CTAs
- Cartoon empty-state illustrations
- Nested scrollbars, icon bloat inside inputs
